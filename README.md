# Анализ распределений данных

Приложение на Python с графическим интерфейсом,
которое по выборке данных подбирает и сравнивает теоретические
распределения и показывает, какое из них лучше.

## Что делает

1. Загружает числовые данные из CSV / TXT / Excel / JSON.
2. Подгоняет параметры 6 распределений методом максимального правдоподобия.
3. Ранжирует их по AIC и BIC, считает веса Акаике (в процентах).
4. Строит гистограмму с наложенной теоретической плотностью (PDF).
5. Строит Q-Q plot для оценки согласия.
6. Даёт сохранить график.

    python main.py

- «Столбец» → выберите признак для анализа (если их несколько).

- «Построить: PDF / Q-Q» — выбранный график.
- «Сохранить…» — экспорт.

## Методика

- **Параметры** оцениваются методом максимального правдоподобия
  (`scipy.stats.<dist>.fit`).
- **AIC** = 2k − 2·ln L — информационный критерий Акаике,
  штрафует за число параметров k.
- **BIC** = k·ln n − 2·ln L — байесовский критерий; сильнее штрафует
  при больших выборках.
- **Вес Акаике**: wᵢ = exp(−Δᵢ/2) / Σⱼ exp(−Δⱼ/2), где Δᵢ = AICᵢ − AIC_min.
  Интерпретируется как относительная вероятность модели i быть лучшей
  среди рассмотренных.

## Ограничения

- На малых выборках (n < 30) оценки параметров неустойчивы.
- Для `rayleigh`, `expon`, `lognorm` данные должны быть положительными;
  при наличии отрицательных значений подгонка может дать ошибку или
  плохое качество.
- AIC и BIC могут давать разные ответы (особенно на распределениях
  с разным числом параметров — например, gamma vs rayleigh).
  Это не баг, а иллюстрация того, что «лучшая модель» зависит от
  критерия.
